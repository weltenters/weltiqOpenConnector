# Questions, feedback, and maintenance

This is currently a project introduction repository. Source code and packages have not been released.

weltiq maintains the project and is not accepting external pull requests at this stage. Questions, documentation corrections, use cases, and connector suggestions are welcome.

## Where to post

- **Discussions** for questions and ideas. For a connector request, include the provider, a link to its official API documentation, and the operations and environment you need.
- **Issues** for specific errors or broken links in the published documentation. Include the page and a brief explanation.
- **Private security reporting** for vulnerabilities. See [SECURITY.md](SECURITY.md).

Please do not submit source patches through issues as a workaround for the pull request policy. You may use Korean or English. Suggestions will be reviewed by the team; they are not commitments to dates or integrations.

Never post API keys, tokens, passwords, account numbers, or personal order histories. Use redacted, minimal examples. Keep discussions respectful and focused on the project.

## 한국어 안내.

현재는 프로젝트 소개 단계이며 소스와 패키지를 제공하지 않습니다. 외부 Pull Request는 받지 않고, weltiq가 유지보수와 향후 릴리스를 담당합니다.

질문·사용 사례·필요한 커넥터는 Discussions, 공개 문서의 오류는 Issues, 보안 문제는 비공개 보안 신고로 알려 주세요. 한국어와 영어 모두 사용할 수 있습니다. 제안에는 공식 API 문서와 필요한 기능을 적고 키·계좌·개인 주문 정보는 포함하지 마세요. 이슈로 소스 패치를 우회 제출하지 말아 주세요.
