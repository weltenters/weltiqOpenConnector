# weltiq Open Connector

**증권사·거래소의 주문과 계좌를 하나의 인터페이스로.**

[English](README.md) · [weltiq 서비스](https://weltiq.ai/) · [질문과 제안](https://github.com/weltenters/weltiqOpenConnector/discussions)

> **프로젝트 소개 · 소스 공개 준비 중.**
> 현재 이 저장소에는 프로젝트 소개와 이용 안내 문서만 있습니다. SDK 소스 코드, 설치 패키지, 릴리스는 아직 제공하지 않습니다. 아래 기능은 공개를 준비하는 범위이며 현재 지원 목록이 아닙니다. 공개 일정은 아직 정하지 않았습니다.

## 왜 만드는가.

증권사와 거래소마다 인증 방법, 주문 형식, 계좌 정보, 오류 응답이 다릅니다. 개발자는 자신의 도구를 만들기 전에 각 기관의 API를 연결하고 변경에 대응하는 일을 반복합니다.

weltiq Open Connector는 선택한 증권사·거래소의 공식 API를 공통 주문·계좌 인터페이스로 연결하는 오픈소스 SDK를 목표로 합니다. 연결 코드를 재사용하고 확인할 수 있게 하면서, 기관마다 가능한 기능과 제한을 분명하게 드러내려 합니다.

전략과 도구는 사용자가 만들고, 커넥터는 API 연결을 담당합니다. 투자 추천이나 수익을 보장하는 프로젝트가 아닙니다.

## 공개를 준비하는 범위.

- 주문 생성·조회·정정·취소, 잔고·포지션을 다루는 공통 인터페이스.
- 선택한 증권사·거래소 공식 API의 연결 코드.
- 실제 자금 없이 첫 연결을 경험할 수 있는 weltiq 페이퍼 트레이딩 클라이언트.
- 기관별 지원 기능과 제한, 오류 처리 계약, 테스트, 연결 가이드.
- 본인 계좌를 다루는 Python 예제와 명령줄 도구.

기관마다 지원하는 기능은 다릅니다. 주문 접수와 체결, 취소 요청과 완료를 구분하고 미지원 기능도 명시하겠습니다. 지원 기관·환경·검증한 기능은 릴리스별로 공개할 예정입니다.

공개 대상은 weltiq가 작성한 API 연결 코드입니다. 증권사·거래소의 실거래 서버 자체를 공개하거나 그 접근 권한을 제공하는 것은 아닙니다. 기관별 계좌, API 이용 권한과 조건은 해당 기관의 안내를 따릅니다.

## weltiq 서비스와의 관계.

| 구분 | Open Connector SDK · 공개 예정 | weltiq 관리형 서비스 |
|---|---|---|
| 실행 위치 | 사용자의 코드와 환경 | weltiq가 운영하는 서비스 |
| 기관 직접 연결 키 | 사용자가 자신의 환경에서 설정·관리 | 지원하는 연결에 서비스의 키 관리 기능 이용 |
| 운영과 기록 | SDK를 사용해 운영·저장 기능을 직접 구성 | 계좌 조회·실행 기록 등은 현재 서비스 기능과 플랜에 따라 제공 |
| 페이퍼 트레이딩 | weltiq 페이퍼 서버를 호출하는 클라이언트 | 서버에서 가상 거래 환경 제공 |
| 공개 대상 | 선택한 연결 코드·계약·테스트·문서 | 호스팅 플랫폼은 별도 제품 |

공개 SDK에는 상용 페이퍼 서버, 로컬 모의 엔진, 전략·백테스트 엔진, 고객 키 보관·과금·다중 사용자 서버가 포함되지 않습니다. 관리형 서비스에서 제공하는 일부 커넥터는 공개 SDK에 포함되지 않을 수 있으며 지원표를 나누어 안내하겠습니다.

첫 연결 가이드는 weltiq 페이퍼 트레이딩을 기준으로 준비합니다. 이 경로에는 weltiq 계정이 필요하며 서비스 이용 범위가 적용됩니다. 지원 기관에 직접 연결하는 개발자에게 weltiq 가입을 필수로 요구하지 않는 방향입니다. 직접 연결 키는 사용자 환경에 두며 weltiq로 자동 전송하지 않습니다.

지금 이용할 수 있는 서비스 연결은 [API·MCP·TradingView 안내](https://weltiq.ai/integrations)와 [문서](https://weltiq.ai/docs)에서 확인할 수 있습니다. 이 서비스 연결과 아직 배포하지 않은 Open Connector SDK는 구분해서 안내합니다.

## 왜 오픈소스인가.

개발자가 인증·주문·오류 처리 방식과 기관별 지원 범위를 직접 확인할 수 있게 하려 합니다. 공통 계약, 테스트, 문서와 변경 이력을 함께 공개해 연결 방식과 한계를 설명하고 유지보수하겠습니다.

SDK는 상업적 재사용을 허용하는 **Apache-2.0** 공개를 계획하고 있습니다. 공개 범위 검토 후 소스와 함께 최종 라이선스를 제공할 예정입니다. 이 안내가 비공개 weltiq 서비스 코드에 라이선스를 적용하는 것은 아닙니다. 기관 API 이용 조건과 시장 데이터 권리는 코드 라이선스와 별개입니다.
