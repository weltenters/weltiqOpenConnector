# Security reporting

There is no released Open Connector SDK or package yet. No version is currently listed as supported.

If you find a security concern involving this project or information published in this repository, use GitHub's [private vulnerability reporting](https://github.com/weltenters/weltiqOpenConnector/security/advisories/new). Do not report credentials or exploit details in public Issues or Discussions.

Include the affected page or component, a concise description, and redacted steps to reproduce. Do not include live credentials, personal account information, or other people's data. A response-time commitment has not been established.
